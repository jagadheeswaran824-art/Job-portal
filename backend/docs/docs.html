REST API Documentation

Complete reference for all authentication, job listings, application management, notifications, analytics, and AI endpoints.

Base URL: /api JWT Bearer Token Supported
Authentication (/api/auth)
POST /api/auth/register Create a new user account

Registers a candidate or employer, creates initial profile records, and returns JWT session token.

Request Body: 
{
  "full_name": "Jane Doe",
  "email": "jane@example.com",
  "password": "StrongPassword123!",
  "role": "job_seeker" // or "employer"
}
POST /api/auth/login Sign in with email and password

Authenticates credentials, returns user profile details and signed JWT Bearer token.

Request Body: 
{
  "email": "jane@example.com",
  "password": "StrongPassword123!"
}
GET /api/auth/me Auth Get authenticated user information

Returns profile information for the token holder.

POST /api/auth/logout Auth Invalidate session and blacklist token

Inserts the bearer token into the MySQL token blacklist, instantly invalidating it.

Job Listings (/api/jobs)
GET /api/jobs List jobs with filters and pagination

Supports search, category, location, job type, salary range, and sorting.

Query ParameterTypeDescription
search / qstringKeyword matching title, company, description
categorystringFilter by domain (frontend, backend, ai-ml, etc.)
locationstringCity or remote location
job_typestringfull-time, part-time, remote, internship
sortstringnewest, salary_high, salary_low, views
POST /api/jobs Employer Create a new job posting

Publish a new job opportunity. Restricted to verified employers and administrators.

AI & Intelligence Service (/api/ai)
POST /api/ai/resume-analyzer AI resume parsing & profile strength scoring

Extracts industry technical skills, assesses profile completeness (0-100), and provides actionable suggestions.

POST /api/ai/match-score Calculate candidate match percentage for a job

Computes skill alignment, returns matched vs missing skills and fit assessment.

POST /api/ai/cover-letter Generate tailored, professional cover letter

Generates a high-converting cover letter based on user skills and targeted company position.

POST /api/ai/interview-prep Generate role-specific interview questions & answer tips

Provides technical, behavioral, and architectural questions with recommended STAR answer talking points.

Notifications (/api/notifications)
GET /api/notifications/unread/count Auth Get live unread notification count

Used by the frontend navbar to show real-time notification badge.
